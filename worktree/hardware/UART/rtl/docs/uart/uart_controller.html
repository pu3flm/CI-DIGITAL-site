uart_controller

Author

Fernando Lessa Magalhães

Updated

September 14, 2026

Purpose

uart_controller is the top-level composition module.

  • It exposes the external register interface.
  • It exposes the external UART pins txd and rxd.
  • It instantiates reg_bank, clock_div, rx_uart, and tx_uart.
  • It contains interconnect wiring only.

Parameter

  • CLK_FREQ: input clock frequency in hertz

Ports

Clock and reset

  • clk
  • rst

Register interface

  • address[1:0]
  • chip_select
  • write_enable
  • read_enable
  • data_in[31:0]
  • data_out[31:0]
  • irq

UART interface

  • txd
  • rxd

Internal Signals

  • reg_reset
  • parity_enable
  • parity_type
  • stop_bit
  • data_len[3:0]
  • baud_rate
  • rx_error
  • rx_done
  • tx_error
  • tx_done
  • tx_start
  • data_tx[7:0]
  • data_rx[7:0]
  • clk_uart_tx
  • clk_uart_rx

Structure

reg_bank connects the external register interface to the internal control and status signals.

clock_div receives clk, rst, and baud_rate, then produces clk_uart_tx and clk_uart_rx.

rx_uart receives:

  • rx_clk = clk_uart_rx
  • rx_start = '1
  • rst = reg_reset
  • rx = rxd
  • length = data_len
  • parity_type
  • parity_en = parity_enable
  • stop2 = stop_bit

rx_uart returns:

  • rx_out = data_rx
  • rx_done
  • rx_error

tx_uart receives:

  • tx_clk = clk_uart_tx
  • tx_start
  • rst = reg_reset
  • tx_data = data_tx
  • length = data_len
  • parity_type
  • parity_en = parity_enable
  • stop2 = stop_bit

tx_uart returns:

  • tx = txd
  • tx_done
  • tx_err = tx_error

Implemented Role

uart_controller does not implement register decode, baud-rate conversion, transmit framing, or receive sampling inside this file.

Its implemented role is:

  • wiring
  • instance ownership
  • signal routing between modules

Source-Comment Intent

Portuguese comments describe:

  • reg_bank as the register-bank instance
  • clock_div as the clock-divider instance
  • rx_uart as the UART receiver instance
  • tx_uart as the UART transmitter instance

The inline connection comments identify the origin of each configuration signal and the destination of each status or data signal.

Observed Behavior

  • The file elaborates as a pure integration layer.
  • The external register interface, internal control wiring, and UART datapath wiring are structurally connected through submodule instances.
