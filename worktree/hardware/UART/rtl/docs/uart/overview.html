UART Overview

Author

Fernando Lessa Magalhães

Updated

September 14, 2026

The implementation is organized around five modules and one shared type definition.

  • uart_controller composes the implementation and connects the external register interface to the UART datapath.
  • reg_bank stores configuration, exposes register reads and writes, captures status, and generates irq.
  • clock_div derives clk_tx_out and clk_rx_out from clk and baud_rate.
  • tx_uart serializes tx_data onto tx.
  • rx_uart captures serial data from rx into rx_out.
  • uart_baud_rate_t defines the supported baud-rate labels.

The top-level control path begins at the register interface.

  • Configuration written into reg_bank drives reg_reset, parity_enable, parity_type, stop_bit, data_len, and baud_rate.
  • baud_rate drives clock_div.
  • clock_div produces clk_uart_tx and clk_uart_rx for tx_uart and rx_uart.
  • tx_uart returns tx_done and tx_err to reg_bank.
  • rx_uart returns data_rx, rx_done, and rx_error to reg_bank.

The top-level data path is split into a transmit path and a receive path.

  • Transmit path: register write to address 1 -> reg1_data_tx -> data_tx -> tx_uart -> txd
  • Receive path: rxd -> rx_uart -> data_rx -> reg2_data_rx -> register read at address 2

reg0_config is the central configuration and status register.

  • Bits 11:0 hold writable configuration fields.
  • Bits 15:12 are written by the implementation to reflect status.

Observed behavior recorded in device terms:

  • In the observed transmit scenario with tx_data = 8'hA5, length = 8, parity disabled, and one stop bit, tx produced a start bit, 8 data bits in least-significant-bit first order, and one stop bit.
  • In the observed receive scenario with an 8-bit frame carrying 8'hA5, parity disabled, and one stop bit, rx_out became 8'hA5 and rx_done asserted at frame completion.
  • In the observed register scenario, a read of address 2 returned the captured receive byte.

Source-comment intent appears mainly in uart_controller, reg_bank, and clock_div.

  • uart_controller comments describe the file as the integration point for the register bank, clock divider, receiver, and transmitter.
  • reg_bank comments describe register ownership, field mapping, and baud-rate conversion.
  • clock_div comments describe clk_tx_out as a 1x baud-rate clock and clk_rx_out as a 16x baud-rate clock.
