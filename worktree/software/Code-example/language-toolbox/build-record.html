Construction result

The image built successfully from Containerfile. The final build uses a digest-pinned Fedora minimal base and exact direct RPM package versions. The three Tcl release executables were checked against their recorded SHA-256 values during the build. gopls was compiled from its pinned Go module version with checksum-database verification.

The implementation contains one small POSIX shell entry point that selects a foreground command. It does not contain a broker. Go is reserved as the selected implementation language if a shared broker or protocol adapter is authorized later.

Protocol result

Executable presence was not treated as proof of a working protocol. Each persistent interface received a real initialization request through standard input and returned a correlated response:

Interface Exchange exercised Result
Tcl language server LSP initialize Passed; identified itself as Tcl LSP and returned server capabilities
Tcl MCP server MCP initialize using protocol version 2025-06-18 Passed; returned a correlated initialization response
Go language server LSP initialize through gopls serve Passed; identified itself as gopls and returned server capabilities
Go MCP server MCP initialize through gopls mcp using protocol version 2025-06-18 Passed; returned a correlated initialization response

These checks establish that the four standard-input protocol processes initialize inside the image. They do not claim that an editor is configured to launch the container or that every later protocol method has been tested.

Execution boundary used for verification

The final smoke and protocol checks ran as disposable rootless Podman containers with:

  • No image pull during verification.
  • No network.
  • A read-only container filesystem.
  • All Linux capabilities dropped.
  • no-new-privileges enabled.
  • Explicit process, memory, and CPU limits.
  • Only a bounded temporary filesystem under /tmp.
  • The image’s unprivileged numeric runtime user.

All smoke inputs and outputs lived in the disposable temporary filesystem. No CI-DIGITAL source file was formatted, compiled, interpreted, or modified by these checks.

Remaining boundaries

  • The image is local and has not been pushed or signed.
  • VS Code is not connected to this image.
  • No broker, API, socket service, Compose topology, daemon, or remote endpoint exists.
  • The persistent language servers are available only as caller-owned foreground processes.
  • Tcl Whitesmiths formatting is not implemented; the packaged Tcl formatter remains K&R-only.
  • The pinned Tcl release artifacts make this build AMD64-specific.
  • The smoke suite verifies representative operations, not complete semantic coverage of every tool or EDA dialect.

Within those limits, the image is built, version-recorded, smoke-tested across every packaged tool family, and protocol-tested at each included LSP and MCP boundary.
